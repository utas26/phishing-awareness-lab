Add Security Lab to your device

Your browser manages installation and asks you to confirm. If an install prompt is available, close this guide and choose Install App again.

  • Chrome on a computer: Open the ⋮ menu, then Cast, save, and share → Install page as app. You may also see an install icon beside the address bar.
  • Microsoft Edge: Open the ⋯ menu, then More tools → Apps → Install this site as an app (some versions show Apps directly). After installation, Edge may offer a desktop shortcut or taskbar pin.
  • Safari on Mac: On macOS Sonoma 14 or later, choose File → Add to Dock.
  • Phone or tablet: Look for Install app or Add to Home Screen in your browser’s menu or Share menu.

Menu names and icon placement vary by browser and device. If installation is unavailable, bookmark this page or open it in Chrome or Edge. If already installed, look for Security Lab in your device’s apps.

All labs still need an internet connection. Installing does not download student records or add special device permissions.
