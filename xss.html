What this model can and cannot show

This is an inert source/sink teaching model. It recognizes only the supplied plain text, simple bold markup, image-event and script-element examples. It never assigns user text to HTML, executes scripts, creates images from input, shows a browser alert, or reads cookies. Unknown markup is marked unsupported; no safety verdict is inferred. Script behavior depends on the real insertion context, so the model does not claim that every HTML assignment executes script tags. Text rendering protects this ordinary comment-text context; HTML, attribute, URL, JavaScript and CSS contexts need appropriate context-specific handling. CSP is defense in depth, not a substitute for safe output.
