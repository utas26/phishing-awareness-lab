Everyday safety

No cyber knowledge needed. Practise protecting accounts, checking destinations and responding to deceptive prompts.

  1. Password Strength

    Compare observed length and limited classroom pattern flags.

  2. Suspicious URLs

    Inspect a link’s destination and choose a trusted route.

  3. QR Phishing

    Follow a decoded QR link and check its redirect trail.

  4. MFA Fatigue

    Reject unexpected requests and recover an account’s simulated session.

  5. Fake Software Update

    Investigate a deceptive download and use a trusted updater.

  6. Browser Permissions

    Remove unwanted access and grant only what a task needs.

Network foundations

Start with Port Scanning to learn the terms. Connect services, password choices and traffic limits to practical defences.

  1. Port Scanning

    Discover preset hosts and interpret simulated port responses.

  2. Wi-Fi Password Auditing

    Test supplied candidates and strengthen the fictional network.

  3. DoS & DDoS

    Compare traffic defences and their effects on a virtual queue.

Secure websites

Basic use of a search box is enough to begin. Explain how treating input as code causes problems, then compare safer handling.

  1. SQL Injection

    Compare vulnerable query behaviour with parameterised input.

  2. Cross-Site Scripting

    Compare unsafe rendering with safe output handling.
